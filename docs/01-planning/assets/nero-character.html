Nero 캐릭터 시안

검은 고양이 Nero 가 1인승 우주선을 타고 사이트의 우주를 비행합니다. 같은 캐릭터를 매끈한 벡터와 픽셀 아트, 두 그림체로 그려 상태별 모습과 실제 쓰일 자리를 나란히 놓았습니다.

상태별 모습

대화 상태에 맞춰 바뀝니다. 고양이라는 말 대신 눈 · 귀 · 꼬리로 기분이 드러납니다.

메인 — 별 사이를 비행

별 그래프 사이를 천천히 가로지릅니다. 누르면 다가와 대화창이 열립니다.

다른 페이지 — 오른쪽 아래에 정박

맨 위로 단추 위에 작은 우주선이 대기합니다. 사이트의 라이트 · 다크 바탕 그대로입니다.

대화창

머리에는 Nero 와 지금 상태, 늘 보이는 안내 한 줄. 답 아래에는 근거 노트가 붙습니다. 답은 시험에서 실제로 받은 것입니다.

보실 것. 두 그림체 중 사이트에 더 어울리는 쪽, 표정이 너무 귀엽거나 차갑지 않은지(시크함), 비행 속도와 정박 크기. 고른 쪽을 다듬어 실제 사이트에 넣습니다.
