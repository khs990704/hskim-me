# 웹 접근성 자체 점검 — KWCAG 2.2

**대상** `https://hskim.me` 전체 (문서 567 + 목록·메인·404, 산출물 572쪽)
**기준** 한국형 웹 콘텐츠 접근성 지침 2.2 (4원칙 · 14지침 · 33검사항목)
**점검일** 2026-09-28 · **점검자** 김희섭 (자체 점검, 인증 심사 아님)

## 요약

|---|---:|---|
| 적합 | 23 | 기준을 만족하고 근거가 있다 |

| 해당 없음 | 8 | 사이트에 그 기능이 없다 (동영상·폼·인증 등) |

이번 점검에서 **7개 항목에서 문제 13곳을 찾아 고쳤다.** 표의 "수정" 칸에 굵게 적은 것이 그것이고, 나머지는 앞서 고친 것이다.

### 점검 방법

1. **산출물 전수 검사** — 빌드된 HTML 572쪽을 스크립트로 훑어 이미지 대체 텍스트, 제목 단계, 표 제목 칸, 새 창 링크, 모호한 링크 글자를 셌다.
2. **키보드 시험** — 헤드리스 Chrome 을 DevTools 프로토콜로 조작해 Tab · Shift+Tab · Enter · Esc 를 실제로 보내고 초점 위치를 기록했다.
3. **코드 검토** — 검색 · 서랍 · 그래프 · 도표 구성 요소의 ARIA 속성과 키보드 처리.
4. **접근성 트리 확인** — 화면 읽기 프로그램은 화면이 아니라 브라우저가 만든 접근성 트리(역할 · 이름 · 상태)를 읽는다. Chrome DevTools 프로토콜로 트리를 꺼내 무엇이 읽힐지 확인했다. VoiceOver 로 직접 들어 본 것은 아니다.
5. **자동 검사** — Lighthouse 접근성 100 (명도 대비 · 접근 이름 · lang 등).

자동 검사는 지침의 일부만 판정한다. Lighthouse 100 은 "기계가 볼 수 있는 항목은 통과" 라는 뜻이지 33개 항목 적합이 아니다.

## 남은 확인

### A. 화면 읽기 확인 — 접근성 트리 (2026-09-28)

VoiceOver 대신 Chrome 의 접근성 트리를 꺼내 확인했다. 화면 읽기 프로그램이 받는 정보와 같다.

| # | 확인 | 트리에 나온 것 | 판정 |
|---|---|---|---|
| 1 | 메인 그래프 | image “지식 그래프 — 문서를 점으로, 문서 사이의 링크를 선으로 그린 3D 그림입니다. 같은 문서는 전체 목록에서 볼 수 있습니다.” | 적합 |
| 2 | 회전 단추 | button “회전 멈춤” pressed=false → 누른 뒤 “회전 다시 시작” pressed=true | 적합 |
| 3 | 문서 서랍 | 여는 단추 expanded=false → dialog “문서 목록” modal=true, 초점 button “닫기” → 닫으면 초점 “문서 목록 열기” | 적합 (복귀는 수정 후) |
| 4 | 검색 | dialog “검색” modal=true, 알림 polite “27개 결과”, 고른 항목 option “Auto MPG Prediction, 프로젝트” + 설명(요약) → 닫으면 초점 “검색” 단추 | 적합 (이름 길이 · 복귀는 수정 후) |
| 5 | 포트폴리오 | heading “NSR” level=1 → heading “프로젝트 개요” level=2 | 적합 |

Safari 는 단추를 눌러도 그 단추에 초점을 주지 않는다. 시험에서는 `click()` 으로 같은 상황을 만들어 확인했다.

### B. 문법 검사 — W3C Nu Html Checker (2026-09-28)

W3C 가 제공하는 공식 검사기(vnu)를 내려받아 산출물 572쪽 전체를 한 번에 검사했다.

| 단계 | 오류 | 경고 |
|---|---:|---:|
| 처음 | 12 (12쪽) | 22 |
| 수정 후 | **0** | 3 (아래 “영어 문서로 보이는데”, 판단상 유지) |

- 처음 오류 12 — Quartz 가 mermaid 코드블록 `<pre>` 안에 자체 확대 단추와 `<div id="mermaid-container" role="dialog">` 를 넣었다. `<pre>` 안에 `<div>` 는 허용되지 않고, 도표가 둘 이상이면 `id` 가 겹치며, 스크립트 전에는 빈 대화상자가 보조기기에 잡힌다. 사이트는 도표 UI 를 직접 그리므로 파이프라인에서 걷어 냈다 (`pipeline/src/html-standards.mjs`).
- 경고 18 — 마크다운 표 정렬(`---:`)이 폐기된 `align` 속성으로 나왔다 → `style="text-align:…"`.
- 경고 1 — 전체 목록의 분류 없는 묶음(소개·포트폴리오) 제목이 비어 있었다.
- 남은 참고 메시지 — “`<br/>` 의 `/` 는 효과가 없다” (React·KaTeX 출력, 표준 허용). “영어 문서로 보이는데 `lang="ko"`” 3쪽 — 목록 페이지라 문서 제목이 영어일 뿐 안내문은 한국어라 `ko` 가 맞다.
