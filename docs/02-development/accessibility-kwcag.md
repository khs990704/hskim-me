# 웹 접근성 자체 점검 — KWCAG 2.2

**대상** `https://hskim.me` 전체 (문서 567 + 목록·메인·404, 산출물 572쪽)
**기준** 한국형 웹 콘텐츠 접근성 지침 2.2 (4원칙 · 14지침 · 33검사항목)
**점검일** 2026-09-28 · **점검자** 김희섭 (자체 점검, 인증 심사 아님)

## 요약

| 판정 | 개수 | 뜻 |
|---|---:|---|
| 적합 | 21 | 기준을 만족하고 근거가 있다 |
| 적합 (대체 수단) | 2 | 3D 그래프 자체는 만족하지 못하지만 같은 내용을 만족하는 경로로 제공한다 |
| 해당 없음 | 8 | 사이트에 그 기능이 없다 (동영상·폼·인증 등) |
| 확인 필요 | 2 | 기계로 판정할 수 없어 사람이 확인해야 한다 |

이번 점검에서 **6개 항목에서 문제 8곳을 찾아 고쳤다.** 표의 "수정" 칸에 굵게 적은 것이 그것이고, 나머지는 앞서 고친 것이다.

### 점검 방법

1. **산출물 전수 검사** — 빌드된 HTML 572쪽을 스크립트로 훑어 이미지 대체 텍스트, 제목 단계, 표 제목 칸, 새 창 링크, 모호한 링크 글자를 셌다.
2. **키보드 시험** — 헤드리스 Chrome 을 DevTools 프로토콜로 조작해 Tab · Shift+Tab · Enter · Esc 를 실제로 보내고 초점 위치를 기록했다.
3. **코드 검토** — 검색 · 서랍 · 그래프 · 도표 구성 요소의 ARIA 속성과 키보드 처리.
4. **자동 검사** — Lighthouse 접근성 100 (명도 대비 · 접근 이름 · lang 등).

자동 검사는 지침의 일부만 판정한다. Lighthouse 100 은 "기계가 볼 수 있는 항목은 통과" 라는 뜻이지 33개 항목 적합이 아니다.

## 1. 인식의 용이성

| 항목 | 판정 | 근거 | 수정 |
|---|---|---|---|

| 1.2.1 자막 제공 | 해당 없음 | 동영상 · 음성 없음 | |
| 1.3.1 표의 구성 | 적합 | 표 563개 모두 제목 칸(`th`)이 있다. 복잡한 표(병합 셀) 없음. 표 제목(`caption`)은 없고 바로 위 소제목이 그 역할을 한다 | |
| 1.3.2 콘텐츠의 선형 구조 | 적합 | 572쪽 모두 h1 이 정확히 하나, 제목 단계를 건너뛰는 곳 0. 읽는 순서 = 화면 순서 | **포트폴리오 14쪽 · 소개에 h1 이 없고 h3 부터 시작** → 나눌 때 제목 단계를 올림 |
| 1.3.3 명확한 지시사항 | 적합 | 조작 안내가 글자로 되어 있다 (“드래그 회전 · 휠 확대”). 모양 · 위치만으로 지시하지 않음 | |
| 1.4.1 색에 무관한 인식 | 적합 | 본문 링크는 색 + 밑줄(내부 실선, 외부 점선). 그래프 노드 색(종류)은 보조 정보이고 같은 구분을 목록 · 검색 결과가 글자로 보여 준다 | |

| 1.4.4 콘텐츠 간의 구분 | 적합 | 영역마다 테두리 · 여백 · 배경으로 구분 | |

## 2. 운용의 용이성

| 항목 | 판정 | 근거 | 수정 |
|---|---|---|---|
| 2.1.1 키보드 사용 보장 | 적합 (대체 수단) | 3D 그래프는 키보드로 조작할 수 없다. 같은 문서를 사이드 트리 · 전체 목록 · 검색으로 모두 키보드로 열 수 있다. 그 밖의 기능(검색 · 서랍 · 테마 · 도표 확대)은 키보드로 동작 | |
| 2.1.2 초점 이동과 표시 | 적합 | 모든 초점 요소에 `:focus-visible` 2px 선. 검색 · 서랍은 열면 초점이 안으로 들어가고, Tab/Shift+Tab 이 안에서 돌고, 닫으면 연 단추로 돌아온다 (키보드 시험 통과) | **초점선이 코드블록에만 있었음 · 대화상자 밖으로 초점이 샜음** → 전역 초점선, 초점 가두기 |
| 2.1.3 조작 가능 | 적합 | 가장 작은 컨트롤 24×24px (대각선 약 9mm, 기준 6mm). 인접 컨트롤 사이 간격 있음 | |
| 2.1.4 문자 단축키 | 적합 | 단축키는 Ctrl/⌘+K 조합뿐. 문자 한 개짜리 단축키 없음 | |
| 2.2.1 응답시간 조절 | 해당 없음 | 시간 제한 없음 | |
| 2.2.2 정지 기능 제공 | 적합 | 메인 그래프 자동 회전에 “회전 멈춤” 단추 (`aria-pressed`). 움직임 줄이기 설정에서는 처음부터 돌지 않는다 | **멈출 방법이 없었음** (조작 중에만 잠깐 멈춤) → 단추 추가 |
| 2.3.1 깜빡임과 번쩍임 제한 | 적합 | 번쩍이는 콘텐츠 없음 | |
| 2.4.1 반복 영역 건너뛰기 | 적합 | 문서 페이지 첫 Tab 에 “본문 바로가기” → `main` 으로 이동 (시험 통과). 메인 · 404 는 반복 영역이 없다 | **없었음** → 추가 |
| 2.4.2 제목 제공 | 적합 | 페이지마다 고유한 `<title>` (“문서 이름 — hskim.me”) 과 h1 | |
| 2.4.3 적절한 링크 텍스트 | 적합 | 링크 글자는 문서 제목. 주소를 그대로 쓴 외부 링크 52개는 목적지가 글자에 드러나므로 허용 | 9/27 경로형 링크 글자를 끝이름으로 |
| 2.4.4 고정된 참조 위치 정보 | 해당 없음 | 전자출판물 아님 | |
| 2.5.1 단일 포인터 입력 지원 | 적합 (대체 수단) | 도표의 두 손가락 확대는 +/− 단추로 대신할 수 있다. 그래프의 두 손가락 확대는 목록 경로가 대체 | |
| 2.5.2 포인터 입력 취소 | 적합 | 모든 동작이 누를 때가 아니라 뗄 때(click) 실행된다 | |
| 2.5.3 레이블과 네임 | 적합 | 보이는 글자가 접근 이름에 들어 있다 (검색 단추 “검색”) | 9/23 검색 단추 이름 일치 |
| 2.5.4 동작기반 작동 | 해당 없음 | 흔들기 · 기울이기 기능 없음 | |
