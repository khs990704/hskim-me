### 9. 코드 문법 강조 (Shiki)
- 파이프라인에 `@shikijs/rehype` 추가 — **빌드 시점에 색을 입혀 JSON 에 담는다.**
  브라우저에서 처리하면 해당 문서가 40개뿐인데도 모든 방문자가 하이라이터를 받는다

- mermaid 블록은 `language-` 접두사가 없어 Shiki 가 건드리지 않음. 다이어그램 변환 경로 유지 확인
- **적용 40개 문서 / 코드블록 123개 중 113개**

#### 집계 오류 정정

언어를 붙이면 오히려 잘못된 색이 칠해지므로 **조치하지 않는다.**

## P4 3D 뉴런 그래프 (같은 날 착수)

**키워드** react-force-graph-3d, MOC 허브 처리, 성운 셰이더, 별 스프라이트, bloom, 시냅스 신호, 줌 제어

### 1단계 — 기능 검증
- `react-force-graph-3d` + `three` 도입. 필요한 API(`postProcessingComposer`, `nodeThreeObject`, `cameraPosition`, `linkDirectionalParticles`)가 모두 노출되어 **three.js 직접 구현 전환 불필요** 판정
- 빌드 시점 좌표를 고정(`fx/fy/fz`)해 시뮬레이션 없이 첫 프레임부터 완성 배치
- 분류별 8색 + 프로젝트 흰색, 연결 수 기준 크기, 1-hop 이웃 강조, 클릭 이동

#### 노드 크기 — 두 번의 오류
1. `nodeVal` 을 반지름으로 착각. 실제로는 **부피**로 해석되어 연결 4개와 121개의 차이가 1.6배뿐이었다 → 원하는 반지름을 세제곱해 전달, 3.6배로 확대
2. 이번엔 `nodeRelSize` 기본값(4) 때문에 **가장 큰 노드의 반지름이 최근접 이웃 거리의 177%** 가 되어 이웃을 덮었다. 군집이 보이지 않던 원인 → 1.35 로 축소(최대 노드가 이웃 거리의 60%)

#### MOC 처리
- MOC 11개가 엣지의 15.2%를 차지하지만 **MOC 링크를 전부 빼도 고립되는 문서는 0개** — 연결 정보를 추가하지 않으면서 배치만 왜곡
- 처음엔 완전 제외 후 군집 중심에 수동 배치 → **Open Source(외부 링크 0개), Mathematics(6%)가 본체에서 이탈**
- 최종: **약한 긴 끈**(distance 110, strength 0.1)으로 남기고 반발 범위를 600 → 300 으로 축소
- 결과: Open Source 가 중앙값의 3.5배 → 2.3배, 군집 분리도 3.55 → 3.17 유지
- 화면에서는 MOC 링크를 평소 숨기고 해당 노드 호버 시에만 표시

### 2단계 — 비주얼
- **성운** — GLSL FBM 노이즈 셰이더. 안쪽을 향한 큰 구. 색 2가지, 밝기 0.62, 흐름 0.008
- **별먼지** — 2400 파티클, 가산 블렌딩
- **별 노드** — 구체(Mesh)는 표면 음영 때문에 '공' 으로 보인다. 카메라를 향한 스프라이트에 중심핵·헤일로·십자 회절을 그려 점광원으로 표현
- **bloom** — UnrealBloomPass. 강도 0.62 · 문턱 0.34 (문턱을 올려 노드만 번지고 선·배경은 선명하게)
- **시냅스 신호** — 평소 1/41 엣지, 호버 경로에 2개

#### 고객 지적으로 발견한 버그 3건
| 증상 | 원인 |
|---|---|
| 마우스 움직일 때 화면 전체가 깜빡임 | `nodeThreeObject` 를 **인라인 함수로 전달** → 렌더마다 새 함수로 인식되어 476개 스프라이트를 통째로 재생성 |
| 클릭 한 번 뒤 회전이 영구 정지 | `addEventListener(..., { once: true })` 로 정지만 등록하고 복귀를 안 넣음 |
| **새로고침하면 성운이 안 붙음** | `ForceGraph3D` 가 동적 import 라 첫 렌더에 인스턴스가 없는데, `useRef` 는 반응형이 아니라 effect 가 한 번 빠져나간 뒤 재실행되지 않음 |

세 번째가 가장 컸다. 개발 중에는 코드 수정마다 재렌더되어 우연히 붙었고, 새로고침해야만 드러났다.
