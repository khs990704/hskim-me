| 9/28 | 활성화 → Pages 연결 → 인증서 → 301 → 코드 전환 |

### 오늘 한 순서
1. **활성화 메일 수신** → Cloudflare 네임서버로 레코드가 그대로 응답하는지 확인 (메일 레코드 무손상)
2. **Pages 에 `hskim.me` 추가** — Custom domains 에서 Active, SSL 발급
3. **Universal 인증서** `*.hskim.me, hskim.me` Active 확인 → 그 뒤에 `www` 를 다시 Proxied 로
   - 순서가 중요했다. 인증서 전에 프록시를 켜면 "This hostname is not covered by a certificate" 경고가 뜬다
4. **Redirect Rule** — `https://www.hskim.me/*` → `https://hskim.me/${1}`, 301, Preserve query string
5. **Always Use HTTPS** 켬
6. 검증 — `www`·`http` 로 들어와도 `https://hskim.me` 로, 경로·쿼리 유지

## 3. 접근성 · 보안 헤더 (공공 웹 표준·접근성 근거 만들기)

NAIS 1 공고의 "공공 웹 표준·접근성·N2SF" 항목을 이 사이트로 채우는 작업을 시작했다. N2SF 는 기관 시스템에서만 생기는 경험이라 사이트로 채울 수 없다고 정리했다 — 대신 NSR 케이스에 "로컬 LLM, 원문은 서버 내부 DB, 보안 접속 절차" 라는 데이터 경계 사실을 보강했다.

- **접근성** — 본문 바로가기, 전역 `:focus-visible` 초점선(라이트·메인 화면 색 분리), 3D 그래프 캔버스에 `role="img"` + 설명, "불러오는 중" 글씨 대비
- **보안 헤더** (`_headers` `/*`) — CSP, HSTS(1년, includeSubDomains, preload 없음), nosniff, X-Frame-Options, Referrer-Policy, Permissions-Policy, COOP
  - 외부 출처는 KaTeX 의 jsdelivr 하나. 예외는 `'unsafe-inline'`(Next.js 인라인 스크립트, Shiki·KaTeX style), `blob:`(mermaid)
  - 적용 전 검증: 헤더를 붙인 로컬 서버 + 헤드리스 Chrome 으로 그래프·mermaid·KaTeX 정상, 위반 0. 시험 페이지로 위반 감지가 동작함도 확인
  - 배포 후 **securityheaders.com A** (A+ 상한은 `'unsafe-inline'`)

- **KWCAG 2.2 자체 점검** (`02-development/accessibility-kwcag.md`) — 33항목: 적합 21 · 대체 수단 2 · 해당 없음 8 · 확인 필요 2 (마크업 검사, 화면 읽기)
  - 산출물 572쪽 전수 스크립트 + 헤드리스 Chrome 키보드 시험(DevTools 프로토콜로 Tab·Esc 전송)
  - 찾아 고친 것: 포트폴리오 14쪽·소개에 h1 없음(나눌 때 제목 단계 올림), 검색·서랍 초점이 밖으로 샘(초점 가두기 + 닫으면 복귀), 그래프 회전 정지 수단 없음(단추), 검색창 레이블·결과 목록 combobox/listbox·결과 수 알림, 도표 단추 이름
  - VoiceOver 대신 접근성 트리(DevTools 프로토콜)로 5개 확인 → 2곳 추가 수정: 검색 결과 하나마다 요약 200자를 읽음(이름을 제목·종류로), Safari 는 단추에 초점을 안 줘 닫으면 페이지 맨 앞으로 튕김(여는 단추로 복귀). 4.2.1 적합 → 적합 22 · 확인 필요 1
  - 검색 입력창 초점선이 Ctrl+K 로 열 때도 뜸 — 글자 입력창은 늘 :focus-visible. Tab 으로 들어왔을 때만 그리게
  - 초점 가두기 1차는 Chrome 이 스크롤 영역에 스스로 주는 초점을 못 잡아 샜다 → `focusin` 되돌리기 추가 후 통과

- **문법 검사** — W3C Nu Html Checker(vnu) 로 572쪽 전수: 오류 12 → 0, 경고 22 → 3. Quartz 가 도표 `<pre>` 에 넣는 자체 UI(`div#mermaid-container role=dialog`) 제거, 표 `align` → `style`, 전체 목록 빈 제목. 남은 경고 3 은 영어 제목 목록 페이지의 언어 오판

  - 시험 중 `pkill -f csp-server` 가 그 명령을 담은 셸까지 죽여 결과가 사라지는 일이 있었다 — 로그를 파일로 받아 해결
