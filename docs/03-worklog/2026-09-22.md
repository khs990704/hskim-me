## 2. 포트폴리오 구조 (D-14)

### 결정 둘
1. **Vault 는 한 파일 그대로.** 빌드 시점에만 나눈다 — Vault `AGENTS.md` 가 *"본문은 Portfolio.md 한 파일에 유지"* 로 정하고 있다
2. **URL 에 분류를 넣지 않는다** — 분류는 바뀌지만 프로젝트 이름은 잘 안 바뀐다. 분류가 URL 에 있으면 프로젝트를 옮길 때마다 링크가 깨진다. 분류는 화면(인덱스 묶음·breadcrumb·사이드 트리)에서 보여준다

### 결과
```
102KB 한 페이지  →  10개 페이지
/about                     소개 + 핵심 역량      1.3KB
/portfolio                 목록 + 한눈에 보기     1.8KB
/portfolio/<프로젝트>        본문 8개           5.5~18.9KB
```
- 문서 내 앵커 16개를 페이지 간 링크로 전환 (`[[#BidVett]]` → `/portfolio/bidvett`)
- 사이드 트리에 `Portfolio` 가지 추가, 분류별 묶음
- 헤더에 `소개 · 포트폴리오 · 전체 목록`
- **PDF 는 사이트에서 제공하지 않기로 확정** (고객이 별도 제작)

### 포트폴리오 ↔ 프로젝트 케이스 상호 링크
같은 프로젝트지만 성격이 다르다 — 포트폴리오는 서술형, 케이스는 구조화 기록.
제목이 같은 것끼리 자동으로 맺어 양쪽 본문 하단에 카드로 표시. **8쌍 전부 매칭.**

## 3. 버그 — 그래프가 통째로 사라짐

고객이 "메인에 지식 그래프가 안 나온다" 고 지적. 콘솔에는 오류가 없었다.

원인은 **`node src/build.mjs` 만 따로 돌린 것.** 좌표를 붙이는 `layout.mjs` 가 실행되지 않아
`pos` 없는 `graph.json` 이 만들어졌고, 화면에서 `[n.x,n.y,n.z] = n.pos` 가 예외를 던졌다.
그런데 **`catch` 가 그 예외를 삼키고 빈 그래프로 넘어가** 화면만 비고 원인은 보이지 않았다.

조치 둘
- `gen-static.mjs` — 좌표 없는 `graph.json` 을 발견하면 **빌드를 중단**하고 `npm run content` 를 안내
- `GraphView` — `catch` 에서 `console.error`, 좌표 일부 누락 시 `console.warn`. **조용히 넘어가지 않는다**
