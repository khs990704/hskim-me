# hskim.me 프로젝트 문서

개인 웹사이트 `hskim.me` 제작 프로젝트의 관리 문서 보관소다.
**개발 소스 코드는 이 디렉터리에 두지 않는다.** 코드는 저장소 루트의 `pipeline/`, `web/`, `infra/` 아래에만 위치한다.

## 이 프로젝트가 무엇인가

Obsidian Vault에 축적된 지식 노트·프로젝트 케이스·포트폴리오를 원본 구조와 내용 그대로 웹에 공개하는 개인 사이트.
메인 화면은 노트 사이의 연결을 뉴런처럼 시각화한 3D 그래프이며, 노드를 클릭하면 해당 노트 페이지로 이동한다.
Obsidian에 새 노트가 추가되면 별도 수작업 없이 사이트에 반영된다.

## 작업 규칙

1. **모든 작업은 시작 전 고객 승인을 받는다.** 개발 계획의 해당 단계를 제시하고 승인을 얻은 뒤 착수한다.
2. 작업 내용이 대화 중 수정되면 **개발 계획 문서를 먼저 갱신하고** 다시 승인을 기다린다.
3. 단계를 마치면 개발 계획의 진행 로그와 그날의 작업 일지를 갱신한다.
4. 작업 중 등장한 기술 개념은 Obsidian Vault의 `00 Inbox/Raw Import/Personal Study/hskim.me/`에 설명 노트로 남긴다.
5. **git 조작은 고객이 직접 한다.** 작업 종료 시점이나 의미 있는 마일스톤에서 제작자는 **커밋 메시지만 제안**하고, `add`·`commit`·`push`는 실행하지 않는다. 메시지는 **한 줄**로 쓴다. 상세 배경은 이 `docs/`에 있으므로 커밋 본문에 중복하지 않는다.
